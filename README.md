# Анализ и прогнозирование временных рядов

В проекте исследуются временные ряды цен на драгоценные металлы, солнечной активности и погоды. Работа начинается с подготовки временной шкалы и данных: проверяются частота наблюдений и пропуски, выполняются интерполяция и обработка выбросов. Затем анализируются тренд, сезонность и автокорреляция, а модели оцениваются на более поздних временных отрезках, чтобы сохранять хронологический порядок.

Для прогнозирования рассматриваются наивный базовый подход, SARIMA и AutoARIMA, экспоненциальное сглаживание Holt–Winters, а также модели CatBoost с лаговыми и скользящими признаками. Дополнительно исследуются DeepAR, N-BEATS и TCN для нейросетевого прогнозирования и GARCH для моделирования изменчивости ошибок. Качество отдельных прогнозов оценивается метриками MAE, RMSE, MAPE и R².

## Структура

```text

│   └── processed/    # подготовленный ряд солнечной активности
├── notebooks/        # исследования по порядку
```

Исходные файлы включают месячный ряд числа солнечных пятен, погодные наблюдения, а также таблицы цен золота и серебра. Ноутбук 02 создаёт `data/processed/sunspots_processed.csv`; ноутбуки 03–05 используют этот подготовленный ряд.

## Запуск

Нужны Python и Jupyter. Установите зависимости для выбранных ноутбуков: `pandas`, `numpy`, `matplotlib`, `scikit-learn`, `openpyxl`, `statsmodels`, `statsforecast`, `utilsforecast`, `etna`, `sktime`, `arch`, `catboost` и `neuralforecast`. В некоторых пакетах состав зависимостей меняется между версиями, поэтому для воспроизводимого запуска лучше использовать отдельное виртуальное окружение.

Запускайте Jupyter из папки `notebooks`, чтобы относительные пути к данным работали:

```bash
cd notebooks
jupyter lab
```


## Используемые методы

- анализ временных меток, регуляризация частоты, хронологическое разделение на train и test;
- заполнение пропусков прямым/обратным заполнением, интерполяцией и импьютерами;
- STL-декомпозиция, ACF/PACF и тест Дики—Фуллера;
- наивный прогноз, SARIMA/AutoARIMA и Holt–Winters;
- лаговые, разностные и скользящие признаки для CatBoost;
- DeepAR, N-BEATS и TCN для многогоризонтного прогноза;
- метрики MAE, RMSE, MAPE и R².
